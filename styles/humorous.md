# Humorous Style

## Purpose

Use when the user wants humor, satire, sarcasm, parody, or a lighter presentation.

## Sources of Humor

Prefer humor based on:

* observation
* irony
* contrast
* exaggeration
* understatement
* timing
* wordplay
* absurdity

## Avoid

Do not:

* explain the joke
* force a punchline into every paragraph
* add excessive emojis
* use generic internet jokes
* manufacture personal anecdotes
* add random slang
* make every sentence funny

## Satire

For satire:

1. Identify the actual target.
2. Preserve the intended criticism.
3. Exaggerate carefully.
4. Keep the underlying observation understandable.

## Sarcasm

Sarcasm works best when the contrast is clear.

Do not make the writing so exaggerated that the original point disappears.

## Cultural Humor

When using local humor:

* use references supplied by the user
* use established context
* avoid stereotypes
* do not invent cultural claims

## Tone

Humor can be:

* dry
* subtle
* sarcastic
* absurd
* playful
* dark
* observational

Use the requested tone rather than defaulting to cheerful humor.
